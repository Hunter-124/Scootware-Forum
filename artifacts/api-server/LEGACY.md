# LEGACY - Express API Server

This directory contains the original Express.js API server.

> [!WARNING]
> This project has been deprecated in favor of the **Next.js App Router** and **Server Actions** in `artifacts/next-app`.
> All API logic and database interactions are now handled directly within the Next.js application.

## Reason for Deprecation
- Unified backend and frontend into Next.js.
- Replaced REST endpoints with Server Actions.
- Improved performance via SSR and simplified data fetching.
